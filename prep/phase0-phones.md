# Phase 0 — Phones and Tablets as Offline Libraries (this week, ~$0–50)

Target: by the end of this, any one of your phones can answer "how do I purify water / treat this wound / get home without GPS service" with **zero signal**.

## Apps (install on EVERY phone/tablet)
- [ ] **Kiwix** — offline reader for Wikipedia and other "ZIM" packs. Content lives in the Kiwix library. Recent Android versions can also share your books over a Wi‑Fi hotspot to other phones.
- [ ] **Organic Maps** (simple, fast) and/or **OsmAnd** (more features, topo/contours) — offline maps + navigation
- [ ] **Offline AI app** — e.g. **PocketPal AI** (Android). Load a 1–4B model (Gemma, Qwen, Llama 3.2 3B). Use it to *find* answers, then confirm them in Kiwix.
- [ ] **A PDF reader** that works offline (the built-in Samsung one is fine)
- [ ] **Meshtastic** app — for later, when you buy LoRa nodes ([comms.md](comms.md))
- [ ] Save the **APK installers** for these apps to a USB drive / SD card, so you can reinstall them on a wiped or replacement phone without the Play Store

## Checklist
- [ ] Fill in [inventory.md](inventory.md) phone/tablet rows (storage, SD slot)
- [ ] Buy microSD cards for anything with a slot (512 GB–1 TB, A2/V30, a name brand from a real retailer — fake cards are common)
- [ ] Install the apps above on every device
- [ ] Download ZIMs over home Wi‑Fi (big files — let them run overnight)
- [ ] Download offline maps; **test navigation in airplane mode**
- [ ] Download the PDF set
- [ ] Load the offline AI model; ask it 5 test questions, then check its answers against WikiMed
- [ ] Print the binder ([print-binder.md](print-binder.md))
- [ ] **Airplane-mode drill:** 30 minutes using only offline stuff. Note the gaps in [log.md](log.md)

## Done when
- [ ] Every phone opens WikiMed, maps, and the survival PDFs in airplane mode
- [ ] At least one device holds full Wikipedia with images
- [ ] The binder is printed and stored with the water/food supplies
