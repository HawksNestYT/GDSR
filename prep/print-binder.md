# The Paper Binder

Electronics fail and run out of power. Paper doesn't. Put this in a 3-ring binder with sheet protectors and keep it with the water and food.

## Section 1 — Contacts & plan
- [ ] Family contact list (phone numbers, addresses — memorize-proof)
- [ ] Meet-up locations (primary, secondary, out-of-area)
- [ ] Radio plan: which channels/frequencies, check-in times ([comms.md](comms.md))
- [ ] Hub Wi‑Fi name, password, IP address

## Section 2 — Medical (print from Hesperian / Red Cross / WikiMed)
- [ ] CPR + choking (adult, child, infant)
- [ ] Bleeding control / tourniquet use
- [ ] Wound cleaning, closure, and signs of infection
- [ ] Burns
- [ ] Dehydration + oral rehydration solution recipe
- [ ] Fever, hypothermia, heat stroke
- [ ] Fractures/splinting
- [ ] Household medication list + dosages + allergies

## Section 3 — Water & food
- [ ] Water disinfection: boiling, bleach dosing table, filter use (CDC/EPA)
- [ ] Water storage rotation schedule
- [ ] Food storage inventory + rotation dates
- [ ] Safe cooking indoors without power (CO poisoning warning!)

## Section 4 — Shelter & power
- [ ] Generator / power station safety (never run a generator indoors)
- [ ] How to shut off gas, water, electric at your house (with photos)
- [ ] Power budget cheat sheet ([power.md](power.md))

## Section 5 — Navigation
- [ ] Printed local street map + state road atlas
- [ ] Routes out of town (2–3 options)

## Section 6 — Tech recovery
- [ ] How to boot and use the hub server (1 page, plain English)
- [ ] How to set up Meshtastic on a new phone
- [ ] Where the backup drive and APK installers are
